<a id='LoggerOptions'></a>
## LoggerOptions

`LoggerOptions<Type, Api>` is an object where:

- key is any [available logger token](#available-logger-tokens)
- value is `boolean` for scalar tokens
- value is `boolean | Record<string, boolean>` for object-like tokens (`headers`, `cookies`, `query`, `params`, `body`, `variables`, `data`)

<a id='LoggerTokens'></a>
## LoggerTokens

`LoggerTokens<Type, Api>` is an object where keys are [available logger tokens](#available-logger-tokens) for the selected `Type` (`request` | `response`) and `Api` (`rest` | `graphql`), and values are token payloads.
