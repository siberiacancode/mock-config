## Overview

Interceptors let you modify requests and responses. Use them to add delays, change headers or status codes, log traffic, or transform data. They can be defined at different levels and apply accordingly.

You can attach interceptors at:

- **Server level** — affects all requests.
- **Component level** — affects configs inside a component.
- **Config level** — affects a specific config.
- **Route level** — affects only one route.

Interceptors support two hooks:

- `request` — runs before matching routes.
- `response` — runs when a route is matched (can transform data).

## Example 1: Global Response Delay (REST)

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    interceptors: {
      response: async (data, params) => {
        await params.setDelay(1000);
        return data;
      }
    }
  },
  {
    configs: [
      {
        method: 'get',
        path: '/users',
        routes: [{ data: [{ id: 1, emoji: '🎉' }] }]
      }
    ]
  }
];
```

## Example 2: Route-Level Response Hook (REST)

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    configs: [
      {
        method: 'get',
        path: '/users',
        routes: [
          {
            data: [{ id: 1, emoji: '🎉' }],
            interceptors: {
              response: (data, params) => {
                console.log(params.getHeaders());
                return data;
              }
            }
          }
        ]
      }
    ]
  }
];
```

## Example 3: Response Status and Headers (GraphQL)

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    baseUrl: '/graphql'
  },
  {
    configs: [
      {
        operationType: 'query',
        operationName: 'GetUser',
        routes: [
          {
            data: { emoji: '🎉', name: 'Nursultan' },
            interceptors: {
              response: (data, params) => {
                params.setStatusCode(200);
                params.setHeader('x-mock', 'graphql');
                return data;
              }
            }
          }
        ]
      }
    ]
  }
];
```
