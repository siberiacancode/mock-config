title: Static Files

Mock Config Server can serve static files. This is a dedicated server feature: you can serve HTML, JSON, images, styles, and any other files directly from your project directory.

## How to enable

Set `staticPath` in the server config. This tells the server to mount static files.

Supported formats:

1. `"/path"` — path to the static directory relative to the process working directory.
2. `{ path: "/path", prefix: "/prefix" }` — directory path + URL prefix.
3. An array of strings and/or objects for multiple sources.

## Examples

Minimal setup:

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    staticPath: '/images'
  },
  ...
];
```

Static files with a prefix:

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    staticPath: {
      path: '/images',
      prefix: '/files'
    }
  },
  ...
];
```

Multiple sources:

```ts
import type { MockServerConfig } from 'mock-config-server';

export const mockServerConfig: MockServerConfig = [
  {
    staticPath: ['/images', { path: '/assets', prefix: '/static' }]
  },
  ...
];
```

## CLI

For a quick start, pass `--staticPath` (or `-s`) when running the CLI.

If needed, combine static hosting with mock routes and the database in a single config.
