---
title: Getting Started
description: Install and set up mock-config-server
---

Install the core package using your preferred package manager:

```package-install
mock-config-server
```

Mock Config can mock REST, GraphQL, and WebSocket flows with the same config, so you can keep one predictable setup for local development and tests.

## 1. Create your config

Create a `mock-server.config.ts` file and export the server configuration as default. The `mock(...)` helper keeps the config compact and typed. This is the default file path, but you can [change it](/docs/cli/run).

<Tabs groupId="transport-config" items={['REST', 'GraphQL', 'WebSocket']}>
  <Tab value='REST'>

```typescript title="mock-server.config.ts"
import { mock, rest } from 'mock-config-server';

type User = {
  id: number;
  name: string;
  role: 'admin' | 'developer' | 'qa';
};

export default mock(
  {
    port: 7777,
    baseUrl: '/api'
  },
  {
    name: 'rest',
    configs: [
      rest.get<{ response: User[] }>('/users', {
        response: [
          { id: 1, name: 'John', role: 'admin' },
          { id: 2, name: 'Jane', role: 'developer' }
        ]
      }),
      rest.get<{ params: { id: string }; response: User }>('/users/:id', ({ request }) => ({
        id: Number(request.params.id),
        name: 'John',
        role: 'admin'
      }))
    ]
  }
);
```

  </Tab>

  <Tab value='GraphQL'>

```typescript title="mock-server.config.ts"
import { graphql, mock } from 'mock-config-server';

type User = {
  id: number;
  name: string;
  role: 'admin' | 'developer' | 'qa';
};

export default mock(
  {
    port: 7777,
    baseUrl: '/graphql'
  },
  {
    name: 'graphql',
    configs: [
      graphql.query<{ response: { data: { users: User[] } } }>('GetUsers', {
        response: {
          data: {
            users: [
              { id: 1, name: 'John', role: 'admin' },
              { id: 2, name: 'Jane', role: 'developer' }
            ]
          }
        }
      })
    ]
  }
);
```

  </Tab>

  <Tab value='WebSocket'>

```typescript title="mock-server.config.ts"
import { mock, ws } from 'mock-config-server';

type ClientMessage = { type: 'echo'; payload: string };
type ServerMessage = { type: 'connected' } | { type: 'echo'; payload: string };

export default mock(
  {
    port: 7777
  },
  {
    name: 'websocket',
    baseUrl: '/ws/users',
    configs: [
      ws.connection(
        (): ServerMessage => ({
          type: 'connected'
        })
      ),
      ws.message(({ raw }) => {
        const message = JSON.parse(raw) as ClientMessage;

        const response: ServerMessage = {
          type: 'echo',
          payload: message.payload
        };

        return response;
      })
    ]
  }
);
```

  </Tab>
</Tabs>

## 2. Start the mock server

Run the CLI and your mocks will be available on `http://localhost:7777`:

```bash
npx mock-config-server
```

> If the package is already installed, you can use the short command `mcs`

## 3. Try your mocks

### Run a request

Use one of the examples below to make a request and confirm that the mock server responds with your configured data.

<Tabs groupId="transport-request" items={['REST', 'GraphQL', 'WebSocket']}>
  <Tab value='REST'>

```typescript
const users = await fetch('http://localhost:7777/api/users').then((response) => response.json());

console.log(users);
```

  </Tab>

  <Tab value='GraphQL'>

```typescript
const users = await fetch('http://localhost:7777/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    query: `
      query GetUsers {
        users {
          id
          name
          role
        }
      }
    `
  })
}).then((response) => response.json());

console.log(users);
```

  </Tab>

  <Tab value='WebSocket'>

```typescript
type ClientMessage = { type: 'echo'; payload: string };
type ServerMessage = { type: 'connected' } | { type: 'echo'; payload: string };

const socket = new WebSocket('ws://localhost:7777/ws/users');

socket.addEventListener('message', (event) => {
  console.log(JSON.parse(event.data) as ServerMessage);
});

socket.addEventListener('open', () => {
  socket.send(
    JSON.stringify({
      type: 'echo',
      payload: 'hello'
    } satisfies ClientMessage)
  );
});
```

  </Tab>
</Tabs>

## 4. Test your mocks

Like any good quick start, it helps to prove the setup in a test runner right away.

### Start the server

Keep the mock server running while your test makes requests to the endpoint.

```bash
npx mock-config-server
```

### Write a test

Create a small Vitest test that calls the running mock server and checks the response.

```typescript title="tests/example.test.ts"
import { expect, test } from 'vitest';

test('returns mocked users', async () => {
  const response = await fetch('http://localhost:7777/api/users');
  const data = await response.json();

  expect(data).toEqual([
    { id: 1, name: 'John', role: 'admin' },
    { id: 2, name: 'Jane', role: 'developer' }
  ]);
});
```

### Run test

Run the test file.

```bash
npx vitest
```

### Expected output

If everything is configured correctly, you should see a passing result like this:

```text

  + responds with the user 0ms

Test Files  1 passed (1)
     Tests  1 passed (1)
  Start at  06:03:11
  Duration  166ms (transform 19ms, setup 0ms, collect 7ms, tests 1ms, environment 0ms, prepare 43ms)
```
