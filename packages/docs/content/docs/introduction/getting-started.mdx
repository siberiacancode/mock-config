---
title: Getting Started
description: Install and set up mock-config-server
---

Install the core package using your preferred package manager:

```package-install
mock-config-server
```

Create a `mock-server.config.ts` file with server configuration and export it as default. This is the default file path, but you can [change it](/docs/cli/run).

<Tabs groupId="type" items={['REST', 'GraphQL']}>
  <Tab value='REST'>

```typescript
import { MockServerConfig, rest } from 'mock-config-server';

export default [
  {
    baseUrl: '/api'
  },
  {
    configs: [
      rest.get('user', {
        response: {
          emoji: '🧊',
          name: 'Siberia can code'
        }
      })
    ]
  }
] satisfies MockServerConfig;
```

  </Tab>

<Tab value='GraphQL'>

```typescript
import { MockServerConfig, graphql } from 'mock-config-server';

export default [
  {
    baseUrl: '/graphql'
  },
  {
    configs: [
      graphql.query('GetUser', {
        response: { emoji: '🧊', name: 'Siberia can code' }
      })
    ]
  }
] satisfies MockServerConfig;
```

  </Tab>
</Tabs>

Start the mock server:

```bash
npx mock-config-server
```

> If the package is already installed, you can use the short command `mcs`

Now you can make a request:

<Tabs groupId="type" items={['REST', 'GraphQL']}>
  <Tab value='REST'>
```typescript
fetch('http://localhost:31299/api/user')
  .then((res) => res.json())
  .then((data) => console.log(data));
```
  </Tab>

<Tab value='GraphQL'>

```typescript
const body = JSON.stringify({
  query: 'query GetUser { name }'
});

fetch('http://localhost:31299/graphql', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

  </Tab>
</Tabs>
