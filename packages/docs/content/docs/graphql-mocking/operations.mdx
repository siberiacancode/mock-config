---
title: Operations
description: GraphQL operation types supported by the graphql namespace.
---

The `graphql` namespace exposes a method for each GraphQL operation type. Every method follows the same call signature — the only difference is the operation type it intercepts.

```ts
graphql.query(identifier, config, settings?)
graphql.mutation(identifier, config, settings?)

graphql.subscription(identifier, config, settings?)
```

Subscriptions use the `graphql-transport-ws` WebSocket protocol. They support matchers through the settings argument, but they do not support polling. Use `next`, `complete`, and `setDelay` in the handler to control the event stream.

<Callout type='info'>
  For the full parameter descriptions, config variants, and types see the [GraphQL API
  Reference](/docs/api/graphql).
</Callout>
