---
title: Methods
description: HTTP methods available in the rest namespace.
---

The `rest` namespace exposes a method for each supported HTTP verb plus two streaming variants. Every method follows the same call signature — the only difference is the HTTP method it intercepts.

```ts
rest.get(path, config, settings?)
rest.post(path, config, settings?)
rest.put(path, config, settings?)
rest.patch(path, config, settings?)
rest.delete(path, config, settings?)
rest.options(path, config, settings?)

rest.sse(path, config, settings?)
rest.stream(path, config, settings?)
```

<Callout type='info'>
  For the full parameter descriptions, config variants, and types see the [REST API
  Reference](/docs/api/rest).
</Callout>
